# Asset Licenses & Attribution Manifest

All 3D geometry (both hero cars, playable cockpit interiors, Mediterranean village architecture, landmark church, coastal viaduct bridge, all four tree species, shrubs, grass tufts, cliffs, rocks, guardrails, start gantry, and street props) is **100% procedurally modeled in TypeScript** inside `src/`. Zero external 3D models are used.

All external PBR textures, HDRI environment maps, botanical foliage atlases, and audio recordings below are verified **CC0 1.0 Universal (Public Domain)** from authorized sources (Poly Haven, ambientCG, OpenGameArt, Freesound) and bundled locally for 100% offline execution.
